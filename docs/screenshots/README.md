## 拍摄建议

- 用深色主题再拍一组会更出彩，能明显看到封面取色的光晕
- 播放页记得选一首**有内嵌封面**的歌，否则显示的是渐变占位图
- 截图尺寸建议保持 1080×2400 左右，避免混用不同比例
