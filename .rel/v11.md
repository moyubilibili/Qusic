## 新增

- **内置更新检查** —— 启动时自动检查（每天最多一次，不打扰），也可在「关于 → 检查更新」手动触发
  - 数据源就是本仓库的 Releases，**不需要自建服务器**
  - 发现新版本时弹窗展示更新内容，可一键「下载并安装」
  - 下载交给系统 DownloadManager，App 被杀也不影响，完成后自动拉起安装界面
  - 连不上 GitHub 会明确提示「可能需要代理」，而不是静默失败

## 修复

- **修复版本号量纲不一致**：`versionCode` 与 tag 解析结果原本不在同一刻度上，会导致「永远提示有新版本」
  - 现在统一为 `主*10000 + 次*100 + 修订`（`1.1` → `10100`）
