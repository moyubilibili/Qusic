## 修复

### 歌单详情改成了独立的二级页面

之前它是**嵌在「曲库」页里面的**：标题栏、分段控件、底部导航全都还挂着，
详情只能挤在剩下的空间里。看起来就是两块东西糊在一起，层级完全不对。

现在它是一块覆盖整个界面的独立页面（连底栏也盖住）：

- 有自己的顶栏：返回箭头 + 歌单名
- 大标题 + 曲目数
- 播放全部 / 分享 / 导出 .Qusic / 重命名 / 删除
- 曲目列表带序号、封面、音源标签、时长，每行可单独移除
- 从右侧滑入 + 淡入，返回时滑出

### 社区帖子详情也改成了独立的二级页面

同样的问题，而且**评论一多就更明显** —— 详情和评论挤在一个滚动区里，
想发评论得先滚过整个帖子。

现在分成三层，各司其职：

```
┌──────────────────────────┐
│ ‹ 返回        帖子        │ ← 固定顶栏
├──────────────────────────┤
│ 标题 / 作者 / 推荐语       │
│ 操作按钮                  │ ← 只有这块滚
│ 评论列表…                 │
├──────────────────────────┤
│ [写点什么…]        发送    │ ← 固定底栏，永远够得着
└──────────────────────────┘
```

### 二级页面的层级保证

迷你播放条升起来时可能盖住详情页。现在打开详情页时会显式
`bringChildToFront` 并抬高 Z 轴，确保它始终在最上层。
