## 新增

### 收藏

播放页那个心形按钮此前是个**摆设** —— `btnHeart` 连触摸事件都没接，按了完全没反应。现在：

- 播放页心形按钮切换收藏（实心/空心）
- 首页长按任意一首歌 → 收藏
- 曲库新增「收藏」分段，可播放全部、可单条移除

收藏**单独存**，不占用歌单；**在线歌曲也能收藏**（只存元数据，播放时重新解析直链）。

### 社区拆成两个板块

```
社区
├── 歌单分享   发布 .Qusic，别人一键导入（原有功能）
└── 论坛       发帖、回帖、带图、带标签、引用歌曲
```

两者共用一张表，用 `board` 字段区分 —— 所以**点赞 / 评论 / 举报 / 管理天然对两个板块都生效**。

### 论坛

| | |
|---|---|
| **#标签** | 正文里写 `#周杰伦` 自动解析。**没有单独的标签输入框** —— 边打字边提示会解析出哪些，少一个步骤，标签也在它出现的语境里 |
| **热门标签** | 标签榜接口 + 点标签看该话题下所有帖 + 一键清除过滤 |
| **图片** | 客户端先压缩（长边 1280，JPEG 质量逐级降到 300KB 以内），服务端再用 `getimagesize` **复验一次** |
| **引用歌曲** | 发帖时附歌（最多 5 首），别人点一下就能播 |

### 社区管理

在此之前 `role = 1` **只是帖子旁边一个徽章**，没有任何实际权限 —— 社区出垃圾内容只能 SSH 上去手写 SQL 删。

现在有 **10 个管理接口 + App 界面**：

```
概览 / 用户 / 歌单 / 举报 / 日志
  ├── 封禁、解封（会踢掉他所有登录态）
  ├── 设为 / 取消管理员
  ├── 重置密码  ← 密码是 bcrypt，反推不出原文，只能设新的
  ├── 标记邮箱已验证
  ├── 下架 / 恢复任意歌单（软删除，数据保留）
  └── 删除评论
```

**每个写操作都记账**（`audit` 表）—— 管理员账号被盗时能查。

**管理员不能封自己、不能撤自己的权** —— 否则一次误点就把自己锁在门外，只能再去改数据库，那这模块就白做了。

## 改进

- **曲库删掉「专辑」「歌手」分段** —— 6 个分段时每格只有 56dp，中文标签挤在一起。现在 4 个（歌曲/最近/歌单/收藏），每格 85dp。
- **「最近」和「收藏」支持多选加歌单** —— 长按进多选、点击勾选、一次加一批。此前只有「歌曲」分段有。
- **首页「最近导入」支持长按** —— 曲库的「最近」有长按，首页漏了。

## 修复

- **酷我封面显示的是 MV 截图** —— `hts_MVPIC` 的 URL 里写着 `wmvpic`，那是**音乐录影带的截帧**，不是专辑封面。优先级写反了，改用 `web_albumpic_short`，尺寸从 120 提到 500。
- **封面缓存不刷新** —— 缓存 key 只看歌曲 id，换封面源后老歌永远显示旧图。改成带封面 URL 指纹。
- **更新检测失效** —— `parseVersion` 用 `minor*100` 而 manifest 是 `minor*1000`，导致永远提示「已是最新」。
- **锁屏样式 + 横屏适配** —— 新增第 4 种播放页样式（模仿 ColorOS 16 锁屏播放器），四种样式都支持横屏分栏。
- **累计收听时长** —— 关于页新增，**只在真正播放时累加**（暂停/缓冲/播完都不算）。
- **新图标** —— MD3 风格的「Q 唱片」（环 + 轴孔 + 尾巴），补齐 `monochrome` 图层支持 Android 13+ 主题图标。
