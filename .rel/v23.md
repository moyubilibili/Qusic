## 新增

### 多选歌曲批量加入歌单

之前加歌只能一首一首来 —— 长按 → 选歌单 → 再长按下一首，几十首要点上百次。现在：

```
① 长按任意一首歌 → 进入多选，这首被勾上
   顶部工具行变成：【已选 1 首】 [全选] [添加到歌单] [取消]
② 继续点其他歌 = 勾选/取消（此时点击不会播放）
③ 点「添加到歌单」→ 选一个歌单，一次全加进去
```

提示会写清楚：`已添加 8 首到「XXX」，2 首已存在`。

**入口是合并的** —— 长按就是入口，选一首就是加一首，选一批就是加一批，不用记两个操作。

细节：

- 歌单列表里只有**全部**歌曲都已在其中时才标「（已全部添加）」—— 部分已有时标了反而误导
- 选「＋ 新建歌单…」也会把选中的全部带进去
- **返回键**先退出多选，不会直接切页
- **切换分段**自动退出多选（选的歌在新分段里可能根本看不见）
- 长按已选中的歌 = 反选

### 每日一句

「关于」页新增一张卡片，每天一句关于音乐的话，中英各半共 59 条。

- **复制** → 把「名句 —— 作者」放进剪贴板
- **换一句** → 随机看另一条，**明天还是回到「每日」那句**

**为什么不联网**：索引就是 `距 1970-01-01 的天数 % 语录数`，同一天永远同一句，跨天自动换。

| | 内置（现在） | 联网 API |
|---|---|---|
| 离线可用 | ✅ | ❌ |
| 需要 key | 不需要 | 多半要 |
| 接口挂了 | 不受影响 | 空白 |
| 体积 | +4 KB | 0 |
| 隐私 | 零请求 | 每次打开都发请求 |

署名只在有把握时才写，拿不准的宁可标「佚名」也不硬安到名人头上。
