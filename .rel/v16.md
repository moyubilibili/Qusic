## 新增

### 歌单
曲库页新增「歌单」分段（现在是 `歌曲 / 专辑 / 歌手 / 最近 / 歌单`）。

- 新建、重命名、删除歌单
- **长按任意一首歌** → 「添加到歌单」，本地和在线歌曲都能放进去
  - 「歌曲」「最近」列表、歌单详情里都能长按
  - **播放页长按队列按钮**同样可以添加
- 已在歌单里的会标注「（已添加）」，避免重复添加
- 删除歌单**只删歌单**，不会删除任何音频文件

### 歌单导入 / 导出（`.Qusic`）
歌单可以导成一个 `.Qusic` 文件发给别人，对方导入即可 —— 方便在社群里互相分享。

- **导出**：歌单详情右上角的「导出」按钮，或歌单行的「⋯」→「导出为 .Qusic」
- **导入**：歌单页的「导入 .Qusic」按钮；重名会自动加序号，不会覆盖已有歌单
- 文件是自描述的 JSON（带 `format` / `version`），以后改结构能做兼容
- **在线歌曲只导出元数据**（音源 + 平台 id + 歌名/歌手/专辑/封面），不导出播放直链
- **本地歌曲按「标题 + 歌手」匹配**本机曲库 —— SAF 的 URI 是每台设备各自授权的，
  别人导出的路径在你这里必然无效，所以只能这样对；匹配不上的条目仍会保留

### 酷狗音源
搜索页现在是 `本地 / 酷我 / 酷狗 / 网易云`。这套接口**完全不需要签名**：

| 用途 | 接口 |
|---|---|
| 搜索 | `mobilecdn.kugou.com/api/v3/search/song` |
| 播放地址 | `m.kugou.com/app/i/getSongInfo.php?cmd=playInfo&hash=` |
| 歌词 | `krcs.kugou.com/search` → `lyrics.kugou.com/download` |
| 封面 | `imge.kugou.com/stdmusic/480/<album_id>.jpg` |

**付费曲目会明确提示**「这首歌在酷狗需要付费，换一首或换个音源吧」，
而不是含糊地说「放不了」或者无限重试。

## 修复

### 弹窗和输入框都不是 MD3 风格
系统 `AlertDialog` 出来是 Material 1 的样子 —— 方角、白底、蓝色按钮；
系统 `EditText` 放进对话框就是一块灰色平板。新增两个自绘组件替换掉全部弹窗：

- **`MdDialog`** —— 28dp 圆角 + `surfaceContainerHigh`，标题 headline-small，
  正文 body-medium，按钮是 `primary` 色 text button，带轻微放大淡入
- **`MdField`** —— MD3 filled text field，12dp 圆角，底部指示线
  （未聚焦 1dp，聚焦 2dp `primary` 并从中心向两侧展开），
  以及最好认的那个特征 —— **浮动标签**：空且未聚焦时停在输入位置当 placeholder，
  聚焦或有内容时缩小上浮到顶部

### 构建脚本的失败判定是错的（严重）
原来用「class 数 < 源文件数」判断 javac 是否失败。但 javac 遇到部分文件报错时，
其余文件照样产出 class —— 于是「202 个 class / 33 个源文件」也被判定成功，
**结果就是用上一次的旧 class 打了包，改动根本没进去**。
现在直接判断 javac 退出码，失败立刻中止。
