这一版集中修歌词页和转场的一堆问题。

## 修复

### 迷你播放条整个不见了
`MiniPlayerBar` 只在视图挂载时读一次播放服务，而 `MainActivity` 是 `bindService`
**异步**绑定的 —— 视图挂载时服务往往还没连上：

```
onAttachedToWindow → instance() == null → 直接 return
→ song 永远为 null → appear 保持 0 → 测量高度为 0 → 整条看不见
```

现在服务连上后由 Activity 主动补一次绑定，并且服务实例不存在时退回**静态快照**，
Activity 重建也不会丢状态。

### 歌词不跟随播放滚动
抽屉式歌词算出了「当前行」却**从来没用它偏移绘制起点**，永远从第 0 行开始铺，
当前行早就跑到屏幕外了。现在以当前行为锚点整体滚动，当前行停在约 30% 处并带缓动。

### 歌词区上下有突兀的黑色硬边
`drawLyricsFull` 结尾铺了两块**写死黑色**的矩形做「上下渐隐」，左右边界还是硬切的 ——
于是一条和底图完全不是一个图层的黑带。现在**一个矩形都不画**，改为歌词文字自身按位置淡出。

### 上滑不跟手
手指拖动时，帧循环里的弹簧还在往旧目标拉，和手指互相打架。
现在拖动期间跳过弹簧并清零速度，松手才交给弹簧收尾。

### 上滑一卡一卡
1. `drawLyrics` 每帧都 `split("\n")` + 逐行折行，疯狂分配对象触发 GC →
   改用与整页歌词同一份缓存，绘制路径零分配
2. 帧循环用了 `postOnAnimationDelayed(frameLoop, 16)`，在帧回调上又加 16ms，
   实际帧间隔约 32ms（≈30fps）→ 改用 `postOnAnimation`，对齐 vsync

### 样式二 / 三的歌词压在进度条上
歌词区起点原为 `subtitleY + 26dp`，进度条在 `subtitleY + 40dp`，两者重叠。
现在统一下移到进度条下方。

### 其他
- 上一版误加的全屏 `saveLayerAlpha`（每帧分配整屏缓冲）已移除
- 歌词区背景误用 `t.surface`（浅色主题是白底），白字白底糊成一片 —— 已移除
- 「歌词」标签不再被返回按钮压住
