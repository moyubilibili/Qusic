## 修复

### 「检查更新」总是提示请求过于频繁

更新检查原先走 `api.github.com`，而未认证的 GitHub API 限制是
**每 IP 每小时 60 次**。走代理时出口 IP 为多人共用，额度极易耗尽 ——
实测当时就是 `HTTP 403` + `x-ratelimit-remaining: 0`。

现在改为**三级来源**，优先使用不消耗 API 额度的方式：

| 优先级 | 来源 | 能拿到什么 | 限流 |
|---|---|---|---|
| ① | `releases.atom` | 标签 + 标题 + 更新日志 | **无** |
| ② | `releases/latest` 的 302 跳转 | 仅标签 | **无** |
| ③ | `api.github.com` | 完整信息 | 60 次/小时 |

APK 下载地址按固定规则拼接（`releases/download/<tag>/Qusic-<tag>.apk`），
不再依赖 API 返回的资源列表。

### 打开 / 关闭播放页没有转场动画

之前用的是 `overridePendingTransition(0, 0)`，等于把转场整个关掉了。

现在：
- **打开播放页**：从底部滑上来，主界面同时轻微缩小并变暗，形成前后层次
- **关闭播放页**：滑回底部，主界面恢复
