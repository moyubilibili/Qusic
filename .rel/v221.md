## 修复

### 检查更新永远显示「已是最新版本」（重要）

`Updater.parseVersion()` 把 tag 转成整数时用的进制，和 `AndroidManifest` 里的
`versionCode` **对不上**：

```java
return major * 10000 + minor * 100 + patch;   // "v2.2" → 20200
```

而 manifest 里 v2.2 的 `versionCode` 是 **22000**（`minor * 1000`）。
于是 `20200 > 22000` 不成立，永远判定为「已是最新」。

| 版本 | manifest versionCode | 修复前解析 | 修复后解析 |
|---|---|---|---|
| 2.0 | 20000 | 20000 ✓ | 20000 ✓ |
| 2.0.1 | 20001 | 20001 ✓ | 20001 ✓ |
| **2.1** | **21000** | 20100 ✗ | 21000 ✓ |
| **2.2** | **22000** | 20200 ✗ | 22000 ✓ |

从 2.0.1 → 2.1 那次，`versionCode` 写成了 `21000`（`minor * 1000`），
但解析仍是 `minor * 100`，两边就此分叉。

> 1.x 时期的 `versionCode` 用的是 `minor * 100`（如 1.9 = 10900），
> 与现在的进制不同。但远端永远是最新的 release，只会解析出 2.x 以上，
> 所以旧的差异不会造成误判。
